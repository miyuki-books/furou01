## 言語の違いで見る並行処理の多様性

プログラミングで「複数の処理を同時に扱う」とは聞こえは単純ですが、実装の方法は言語によって大きく異なります。どの言語を選ぶか、その言語の並行処理パラダイムをどこまで理解するかで、実装の安全性と効率が左右されます。

並行処理を学ぶ際には、単一言語の深い解説だけでなく、複数言語での実装パターンの違いを知ることが有効です。言語によって「スレッド」「チャネル」「所有権」といった概念の位置づけが異なるため、別言語での学習が理解の根を深くするからです。

## 本の選び方

### Rust で学ぶ「安全性重視の並行処理」

[詳解Rustプログラミング](/go/9784798160221) は、Rust の所有権システムと借用チェッカーが並行処理にもたらす制約と自由を正面から扱う書籍です。

Rust は「複数の所有者が同時にデータを変更する」ことをコンパイル時に禁止します。この制約は一見厳しいですが、データ競合（race condition）を原理的に排除する安全性をもたらします。本書では、この安全性がどのようにして実現されているのかを、言語仕様の側面から学べます。

メモリ安全性が重要な領域（システムソフトウェア、組込み、エッジコンピューティング）での実装を想定する場合、Rust の並行処理の考え方は必読です。

### Go で学ぶ「実用的な並行処理」

[現場のGoプログラミング　実プロジェクトで役立つイディオムとテスト](/go/9784295025733) は、Go の goroutine とチャネルを使った並行処理が、実装の段階でどう機能するかに焦点を当てた書籍です。

Go では並行処理がシンプルで、goroutine の軽量性により多数の並行タスクを低オーバーヘッドで管理できます。本書は「言語仕様だけでなく、実プロジェクトでの意思決定」を対象としており、パフォーマンス測定、テストの書き方、落とし穴とその回避法まで網羅しています。

ネットワークサービス、API サーバー、バックエンド処理の実装を想定する場合、Go での実践的なノウハウは即座に役立ちます。

### Go の基礎から学ぶ「並行処理の入門」

[入門Goプログラミング](/go/9784798158655) は、Go の文法と思想を基礎から解説する教科書です。並行処理も一章として網羅しており、goroutine とチャネルの概念を言語の全体像の中で理解できます。

Go の設計思想は「シンプルさ」です。複雑な並行制御ツール（ミューテックス、セマフォ、条件変数の細かい調整）が不要な場合も多く、チャネルによる通信中心のアプローチが優先されます。これらの原則は、Go 固有のものではなく、並行処理全般の思考基盤になり得ます。

Go が初めての言語、または並行処理の経験が浅い場合は、本書で基礎を固めた後、実践書に進む流れが効果的です。

## 3冊の学習順序

次のいずれかの順序が考えられます。

1. **基礎を優先する場合**：入門Goプログラミング → 現場のGoプログラミング → 詳解Rustプログラミング
   - Go で並行処理の基本を習得した後、Rust の安全性モデルを学ぶ流れ

2. **安全性重視の場合**：詳解Rustプログラミング → 現場のGoプログラミング → 入門Goプログラミング
   - Rust で言語の制約から学んだ後、Go で制約の少ない実装の自由度を感じる流れ

3. **実装中心の場合**：現場のGoプログラミング → 入門Goプログラミング → 詳解Rustプログラミング
   - 実装ノウハウを優先し、その背後にある言語設計を理解する流れ

読者の背景（Web 開発経験者か、システムプログラミング経験者か）や時間的余裕に応じて、どの本から入るかを選択してください。
