## 目的別ガイド

コード品質を上げたいなら、何からはじめますか？

基礎理論が知りたければ**Clean Code**。実践的なテクニックが欲しければ**アート・オブ・クリーンコード**。
すぐに使えるレシピを探しているなら**クリーンコードクックブック**。

3冊の狙いと読者像を見てみましょう。

## 各書の特徴

### [Clean Code (クリーンコード) : アジャイルソフトウェア達人の技](/go/9784048930598)

Robert C. Martin が2008年に著した古典です。邦訳は2017年。

読者は「コードを読みやすくするとは何か」という根本的な問いに向き合いたい開発者。
関数設計・命名・クラスの責務・エラーハンドリング・テストなど、
実装レベルの判断基準を一貫した視点から解き明かします。

初版から15年が経っても、その判断基準は色褪せません。
ただし分量が多く（400ページ超）、例題も古い言語で書かれています。
時間に余裕がある学習段階で通読する本です。

### [アート・オブ・クリーンコード](/go/9784320125896)

Christian Mayer による最新作。邦訳は2025年8月の発行です。

Clean Code よりコンパクト（250ページ強）でありながら、
シンプルで読みやすいコードを書くためのベストプラクティスを集めています。

変数名・関数・クラス設計から、SOLID原則、デザインパターンまで、
モダンなPython・JavaScript・TypeScriptの例とともに紹介。
Clean Code の「続編」というより「現代版入門書」として機能します。

### [クリーンコードクックブック](/go/9784814400973)

Maximiliano Contieri による「レシピ集」です。

「メソッドを小さく保つ」「ネストを減らす」「条件分岐を簡潔に」など、
すぐに実践できる改善テクニックが短編形式で並んでいます。

Clean Code のように「なぜそうするか」の理論を深掘りするより、
「具体的には何をするか」の実装パターンを優先。
コードレビューで指摘される項目の「直し方の辞書」として使えます。

## 読み方の例

**急ぎの場合** → アート・オブ・クリーンコード + クリーンコードクックブック。
入門から実践まで、2冊で一連の流れが抑えられます。

**深く学びたい場合** → Clean Code を軸に、アート・オブ・クリーンコードで補足。
両者を比較読みすることで、時代を超えた原則と最新のトレンドが見えます。

**困ったときのリファレンス** → クリーンコードクックブック。
具体的な問題に直面したときの「正解例」を素早く参照できます。
